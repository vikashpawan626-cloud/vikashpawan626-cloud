### 🌟 Featured Project: [ShoonyaOne](https://github.com/vikashpawan626-cloud/ShoonyaOne)
> 🤖 **ShoonyaOne** is an autonomous personal AI assistant built for Android & Termux environments, powered by Google's Gemini models with a multi-step **Think ➔ Plan ➔ Execute ➔ Verify** autonomous ReAct loop.
- 📱 **25+ Tools**: Real device hardware control (torch, battery, volume, screen brightness), contacts, calling & SMS automation.
- ⚡ **Web UI & PWA**: Clean mobile-first web interface with real-time hardware status indicators.
- 🧠 **Autonomous Planning**: Breaks down complex user requests and executes them with tool verification.
